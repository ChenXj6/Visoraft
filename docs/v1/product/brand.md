# Visoraft 品牌与界面方向

## 定位

- 名称：Visoraft。
- 中文描述：本地媒体操作台。
- 标语：把媒体任务放上轨道。
- 语气：专业、清晰、克制；不使用“全自动无风险”等无法验证的承诺。

## Logo

标志由三条媒体轨道汇入向前的播放标记，红色竖线代表剪辑台上的播放头。造型采用平面硬边结构，不沿用原项目名称、播放按钮外形或配色。

主文件：[`assets/brand/visoraft-mark.svg`](../../../assets/brand/visoraft-mark.svg)。

## 界面原则

- 总览先回答“现在发生了什么、哪里需要处理、系统是否健康”。
- 任务页展示真实状态、当前步骤、进度、下一动作和可解释错误。
- 复杂设置按用户目标渐进展开，不把 172 个控件堆在单一长页。
- 视频 URL 只是任务执行输入，不做独立来源记录或权利页面。
- 桌面和 390px 移动端都能完成核心操作，不能只缩小表格。
- 延期能力不显示可点击假按钮；消息推送在实现前完全隐藏。
- 不使用大面积渐变、霓虹色、过度圆角或等权卡片墙；主要信息以轨道、台账和工作面组织。
