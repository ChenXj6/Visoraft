# Visoraft V1 资料索引

V1 是当前可运行的深度本地化产品：YouTube 发现/监控、下载与媒体检测、字幕/ASR/翻译/质检、人工或自动审核、转码以及 Bilibili/AcFun 投稿。

**状态：项目总体 `in_progress`。Bilibili 曾有真实投稿证据；AcFun 真实凭证闭环和其他验收缺项仍不能视为完成。**
