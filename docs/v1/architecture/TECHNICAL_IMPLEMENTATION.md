# Visoraft 技术实现说明

本文档面向开发、运维和许可证审计人员。产品页面只展示用户完成任务所需的信息，运行框架、进程边界和许可约束集中记录在这里。

## 系统边界

- React 19 管理端：任务、审核、监控、投稿、设置和文件中心。
- Go 服务：持久化 API、任务状态机、审核决策、监控调度、平台投稿编排和文件目录聚合。
- Python 媒体服务：`yt-dlp` 下载、语音识别接入、字幕处理和媒体命令执行。
- PostgreSQL：任务、步骤、审核、监控、投稿、配置版本和媒体资产清单。
- RabbitMQ：需要重试、恢复和多实例消费的后台任务。
- S3 兼容对象存储：下载文件、字幕、封面、质检报告和最终媒体。

## 媒体处理与许可边界

发行镜像采用可核验的 LGPL FFmpeg 构建，并在构建与运行检查中拒绝 GPL、nonfree 和 version3 选项。默认 H.264 软件编码路径使用 OpenH264，不随镜像提供 libx264 或 libx265。平台需要特殊媒体参数时，通过受控白名单传入，后台仍会执行禁止项、滤镜冲突和编解码边界检查。

## 文件访问

前端文件中心读取 Go 服务聚合的持久化媒体资产清单。文件内容通过短路径的受控内容接口读取，不向浏览器暴露对象存储密钥、宿主机目录或内部存储地址。

## 密钥处理

Cookie、平台登录凭据和第三方 API Key 只保存加密密文。页面返回值只包含“已配置”状态，不回显原始密钥；执行任务时由对应后台服务短时读取。

## 版本与恢复

处理策略、提示词、投稿策略和媒体预设按版本保存。任务创建时冻结所需配置快照，后续修改不会改变运行中的任务；失败步骤由队列重试和显式人工恢复共同处理。
