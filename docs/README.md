# Visoraft 版本资料索引

本目录按产品代际归档。任何文档、流程图、源码说明和测试证据都必须先确定归属版本，再写入对应目录。

| 版本 | 产品含义 | 状态 | 入口 |
| --- | --- | --- | --- |
| V1 | YouTube 内容发现、深度字幕本地化、审核、Bilibili/AcFun 投稿 | 现有可运行源码；项目总体仍为 `in_progress` | [V1 索引](v1/README.md) |
| V2 | 多平台来源、多目标、用户可编排的内容自动化平台 | 产品与技术规划中，尚未实现 | [V2 索引](v2/README.md) |

## 统一目录规则

```text
docs/
  v1|v2/
    product/       产品定位、范围、路线图、平台矩阵
    architecture/  系统架构、数据模型、ADR、接口设计
    code/          源码归属、目标模块、示例契约
    planning/      当前公开状态；详细实施日志只保留在本地
    research/      竞品与历史调研（需要时建立）
    testing/       测试计划、验收矩阵、证据索引
diagram/
  v1|v2/           SVG 流程图；PNG 为本地渲染证据
artifacts/
  v1|v2/           截图、报告、日志、转储等本地证据，默认不入 Git
```

共享的许可证、交付准则、依赖声明和仓库入口继续放在仓库根目录；它们不属于某个产品版本。

源码不复制到 `v1/`、`v2/` 两套目录。当前源码路径保持可构建，版本归属由 [代码版本策略](CODE_VERSIONING.md) 和各版本源码地图管理。

流程图入口见 [`diagram/README.md`](../diagram/README.md)。本地实施日志、一次性迁移记录和真实验收证据按公开仓库边界排除。
